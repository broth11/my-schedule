# Roadmap

## MVP 1: Schedule Viewer

Focus on preserving and hardening the current schedule viewer.

- Monthly view.
- Daily view.
- Manual block selection.
- Teacher schedule PDF import.
- ICS import.
- Theme and color preferences.
- localStorage persistence.
- Print/PDF export.
- Parser tests for known schedule PDF block expressions.
- Static school-year JSON data with ICS-to-JSON conversion and validation tooling.

## MVP 2: Day Detail Panel

Add a focused day detail panel after MVP 1 is stable.

- Show selected day's cycle day and blocks.
- Show imported schedule details for that day.
- Keep the panel read-only and schedule-focused.

## Non-Goals

- No manual reminders or task system.
- No recurring task logic.
- No notifications.
- No Google Calendar write-back.
- No editing Google Calendar events.
- No backend database.
- No cross-device teacher accounts.
- No admin dashboard.
